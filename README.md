# ogre3dSelfLearning
This repository contains Ogre3d Sinbad usage for self learning. This will be my learning of Game Development as a hobby. 

As a developer, I wanted to dive right into game development rather than go through Hello World tutorials. I see them as a waste of time in my opinion, because it gives a feeling that I'm still in the 80's, where people used 2MB RAM as a hard drive and for them, outputting something on the screen was a great accomplishment.

In today's time, when all the tools are availaible then why is there a need for such tutorials? I just don't get it. So, for those who like to dive into game development and learn by jumping into the water instead of learning what water consists off this is a good starting point in my opinion. I'll share my learning experience about game development, and maybe one day this will become a full game tutorial on Ogre3d. But it depends on my learning and if I can keep my learning passion alive.

As I found out that there is more than meets the eye in Ogre3d. I've tried breaking the code of Sinbad Character and failed. Therefore, I decided to use what I have in Ogre3d and learn to merge things as the first step. So, this code is best to start adding materials and understand the game development through the eyes of the ogre itself. :)
